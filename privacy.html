Черновик перед публикацией. Здесь будет указано, кто является оператором персональных данных и как с ним связаться.

Какие данные собираются

Имя, контакт для связи (Telegram и/или e-mail), ответы анкеты и информация, которую пользователь добровольно указывает в комментарии.

Для чего используются данные

Для обработки предзаписи, связи по выбранному курсу, организации обучения и обработки покупки.

Хранение и обработка

Данные хранятся только столько, сколько необходимо для заявленных целей, и могут обрабатываться техническими сервисами, которые обеспечивают работу формы, связи и оплаты.

Как отозвать согласие

Пользователь может запросить прекращение обработки или удаление данных по контактам оператора, которые будут указаны здесь перед публикацией.

Перед запуском нужно добавить ФИО/наименование оператора, e-mail для обращений и при необходимости сведения о конкретных сервисах обработки данных.
