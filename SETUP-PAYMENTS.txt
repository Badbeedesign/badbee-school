BADBEE SCHOOL — подключение оплаты

На сайте уже готов платёжный сценарий для НЕЙРО и POINT:
1. Покупатель заполняет имя и контакт.
2. Сайт отправляет заказ на paymentEndpoint.
3. Серверный endpoint создаёт платёж у выбранного провайдера.
4. В ответ возвращает JSON: {"checkoutUrl":"https://..."}
5. Покупатель переходит на защищённую страницу провайдера.
6. После оплаты провайдер возвращает пользователя на payment-success.html.

Важно: секретный ключ платёжного сервиса НЕЛЬЗЯ хранить в config.js или другом фронтенд-файле. Нужен серверный endpoint / serverless function / Apps Script только если конкретный провайдер позволяет безопасно работать таким способом.

Чтобы включить оплату:
- выберите провайдера (например, ЮKassa / CloudPayments / Т-Банк Эквайринг);
- получите merchant/shop ID и секретный ключ;
- создайте серверный endpoint по API провайдера;
- вставьте URL endpoint в config.js -> paymentEndpoint.

Сумма для НЕЙРО: 13 000 RUB.
Сумма для POINT: 13 000 RUB.

После выбора провайдера можно добавить webhook, чтобы выдавать доступ только после подтверждённого статуса платежа.
